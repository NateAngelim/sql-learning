# SQL Studies

Repository dedicated to my SQL studies and practical exercises.

The goal of this repository is to document my progression in SQL, starting with fundamental queries and gradually moving toward more advanced techniques used in data analysis.

## 📚 Topics

The repository will progressively cover:

* `SELECT` and column selection
* `WHERE` and filtering
* `DISTINCT`
* `ORDER BY`
* Aggregate functions
* `GROUP BY`
* `HAVING`
* `CASE`
* `JOINs`
* Subqueries
* Common Table Expressions (`CTEs`)
* Window Functions
* Data cleaning and transformation
* Analytical queries

## 🎯 Learning Approach

The exercises are focused on practical application rather than memorizing syntax.

For each topic, I aim to:

1. Understand the underlying concept.
2. Write queries from scratch.
3. Solve practical exercises.
4. Review and improve previous queries.
5. Apply the concepts to progressively larger datasets and analytical problems.

## 📊 Dataset

The initial exercises use job-posting data, including information such as:

* Job title
* Job location
* Country
* Salary
* Job platform/source
* Job type

The dataset is used to practice SQL in a context related to data analysis and the job market.
